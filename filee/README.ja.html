ドラッグで使う、無料のオープンソースのファイル変換ツール。
キー（Ctrl、macOSではOption）を押しながらファイルをドラッグし、カーソル位置に開くドーナツメニューの形式にドロップするだけ。

インストール

Releasesからダウンロードしてください。

  • Windows 10/11：Filee-<version>-win-Setup.exeを実行するか、win-Portable.zipを展開してFilee.exeを実行します。
    • セットアップはFilee独自のインストーラーで、Fileeと同じ言語で表示され、PCにほかのソフトは必要ありません。
    • エクスプローラーのメニュー、サインイン時の起動、fileeコマンド、追加の変換エンジンを選べます。
    • サイレントインストールにはInno Setupと同じスイッチ（/VERYSILENT /SUPPRESSMSGBOXES）が使えます。
  • macOS 13以降（プレビュー版）：osx-arm64またはosx-x64のパッケージを展開し、./install.shを実行します。
    • または.dmgを開いてFileeを「アプリケーション」へドラッグします（fileeコマンドはinstall.shで追加されます）。
    • まだ公証を受けていないため、初回起動時は「システム設定」→「プライバシーとセキュリティ」→「このまま開く」で許可してください。
  • Linux x64/ARM64（Ubuntu 22.04以降）：パッケージを展開して./install.shを実行します（root権限は不要、Python 3が必要）。
    • ドラッグ操作にはX11が必要です。 Waylandでは、ドロップ領域とファイルマネージャーの右クリックメニューを使ってください。

新しいバージョンが出るとメニューでお知らせし、設定とエンジンはそのままでFilee自身が更新します。 更新後は、新機能を数枚のスライドで紹介します。

Windows：Fileeが起動しない（ウィンドウもエラーも出ない）場合 長い間更新していないWindows 10を、ハードウェア強制スタック保護（CET）に対応したプロセッサーのPCで使っていると起こります。 Windowsはこの保護を有効にしますが、.NETに必要な機能が欠けているため、Fileeとセットアップがすぐに終了します。

  • 推奨：Windows Updateで利用できる更新プログラム（最新の累積更新プログラム）をインストールしてください。
  • 更新できない場合：Fileeだけこの保護をオフにすると、たいていは起動します。 管理者として開いたPowerShellで次を実行します。
Set-ProcessMitigation -Name Filee.exe -Disable UserShadowStack
Set-ProcessMitigation -Name filee-cli.exe -Disable UserShadowStack

セットアップも、そのファイル名（例：Filee-<version>-win-Setup.exe）で同じように実行してください。 ポータブル版のZIPなら上の2行だけで済みます。 元に戻すには、「Windows セキュリティ」→「アプリとブラウザー コントロール」→「Exploit Protection の設定」→「プログラム設定」で該当する項目を削除します。

機能

  • カーソル位置にドーナツメニュー：キーを押しながらファイルをドラッグし、形式の上にドロップするだけ。 ファイルに合う形式だけが表示されます。
  • ブラウザーから直接：Chrome、Edge、Firefox、Safariから画像、ファイルへのリンク、ダウンロードも同じようにドラッグできます。
    • Fileeはダウンロードフォルダーに保存して（変換後のファイルだけを残すこともできます）変換します。
    • リンクはブラウザーのログイン情報を使わずにダウンロードします。
  • ファイルの種類ごとのドーナツメニューはドラッグ＆ドロップで並べ替えられ、次の項目をプリセットで設定できます：
    • 品質、サイズ、DPI
    • PDFのページと圧縮
    • 動画と音声
    • 保存先、ファイル名
  • ドーナツメニューの裏面：開いている間にTabキーを押すかマウスホイールを回すと裏返り、使用頻度の低い形式やツールが表示されます。
  • 変換の前にトリミング：「トリミング」で画像を1枚ずつ開けます。 枠をドラッグして比率を選ぶと、その部分だけを保存します。
  • 複数のファイルをまとめて並列で変換します。 複数の手順が必要な変換（HWP → HWPX → DOCX）も、経路を自動で見つけます。
  • 監視フォルダーに入ったファイルを、すべて自動で変換します。
  • 最近の変換はホームにサムネイル付きで表示され、変換結果を開いたり、別のアプリで開いたりできます。
  • ほかの使い方：右クリックメニュー、キーボードショートカット、ドロップ領域、fileeコマンド。
  • ライトテーマとダークテーマ。 アクセントカラーとドーナツメニューの不透明度も選べます。 English、Español、日本語、한국어、简体中文、繁體中文、Polski、हिन्दी、Русский、العربية（右から左へ表示）、Português (Brasil)、Français、नेपाली、ไทย、Türkçe、Português (Portugal)、Deutschに対応。

コマンドライン

fileeコマンドは、アプリと同じエンジンとプリセットを使います（セットアップまたはinstall.shで追加されます）。

filee convert photo.heic --to jpg
filee convert *.png --to webp --quality 80 -o converted
filee watch D:\Inbox --to pdf --move-originals

すべてのコマンドとオプションは、filee.sh/cliまたはfilee helpで確認できます。

開発

Windows、macOS、Linuxで、.NET 10 SDKを使ってビルドします。

git clone https://github.com/KnifeLemon/Filee.git
cd Filee
pwsh build/fetch-engines.ps1 -Only rhwp,pandoc   # optional engines
dotnet run --project src/Filee.App
dotnet test
