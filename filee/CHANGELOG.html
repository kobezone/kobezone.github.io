Changelog

What changed in each version of Filee, for the people using it. The release workflow puts the section of the version it publishes under "What's Changed" in the GitHub release notes, above the list of pull requests.

Add a ## <version> section before tagging a release. Write what someone using Filee notices: what's new, where to find it, what it does and doesn't do.

Start the section with an <!-- update --> block (hidden on GitHub). The app's update notice shows its level and its one-line summaries in the user's language (any language Filee ships: ko, en, zh, pl, pt-BR, …; a line per change, a language may repeat; a language without lines shows the English ones):

  • required: wrong or lost results, security, Filee not starting. The card shows every time Filee starts.
  • recommended: bug fixes. The card shows once per version.
  • optional: new features only. No card, the sidebar button only.

2.1.0

New

  • Signed for Windows (issue #333). 2.1.0 is the first Filee whose Windows files are code-signed, with a Certum open source certificate issued to "Open Source Developer MYEONGGU KIM". Filee-2.1.0-win-Setup.exe, the portable zip's files, Filee.exe, filee-cli.exe, the uninstaller and the bundled programs and libraries that came unsigned (rhwp, 7-Zip and most libraries) carry that signature; files their makers signed (.NET, ImageMagick, the Microsoft C++ runtime …) keep their own. Smart App Control and other Application Control policies, which could refuse to load parts of an unsigned Filee, let it start, antivirus programs flag it less often, and Windows names the publisher instead of "Unknown publisher". SmartScreen can still warn about a new release until it has been downloaded enough ("More info" → "Run anyway"). macOS packages stay ad-hoc signed and not notarized.

  • Text recognition (OCR) (issue #288, by @cre8ive-marketing; Apple Vision by @smjrifle). Scans and pictures become searchable PDFs, and their text goes into DOCX, TXT, Markdown and HWPX: a scanned PDF → DOCX gives text you can edit instead of pictures of the pages. Tick Recognize text (OCR) in the PDF card of the preset editor (for PDF, DOCX, TXT, Markdown and HWPX targets) and pick the language of the text: 69 languages, each downloaded the first time it's needed (0.4 to 10 MB). The new Searchable PDF preset does it in one step; it's in the preset list, not on a donut, so add it in Settings → Donut toolbar. Pages that already have text are copied as they are, and a PDF with text on every page is left as it is, with a note. Bookmarks and form fields of a scanned PDF don't come along.

    • On Windows, Tesseract is a new engine in Settings → Engines (offered, not installed for you). On Linux and macOS, Filee uses the system's Tesseract (sudo apt install tesseract-ocr, brew install tesseract).
    • On macOS, Apple Vision reads the text with nothing to download. Languages it can't read (Hindi, Nepali, Greek …) need Tesseract.

  • Everyday media tools (by @cre8ive-marketing). Eight new presets:

    • Compress image: the same format, smaller (quality 75, never above a JPEG's own; PNG and TIFF losslessly).
    • Compress video: H.264 MP4 at the Small quality, at most 1080p. Compress audio: AAC M4A at 128 kbit/s.
    • Extract audio: a video's sound as M4A, copied without re-encoding when it's AAC or ALAC.
    • Merge videos and Merge audio: the files joined into one, in the order you set in the merge order window. Clips recorded the same way are copied as they are; others are fitted into the first clip's frame and encoded.
    • Video from images: the pictures as a 1080p MP4, 3 s each with 1 s crossfades (both can be changed in the preset editor), up to 300 pictures.
    • Remove metadata: a copy named {name}_clean without EXIF, location, comments, tags, chapters, or a PDF's document information. Videos and audio aren't re-encoded, and MKV subtitle fonts stay.

    A compressed result that isn't smaller is replaced by the original, with a note. A new library has them on the back faces of the image, video, audio and PDF donuts (Extract Live Photo video leaves the image donut's back face to make room, and stays in the preset list); an updated library gets them where a back face has room, and Extract audio takes the M4A slice's place on the video donut's back. Video from images is on no donut. All but Compress image, and Remove metadata for pictures and PDFs, need FFmpeg.

  • Cut a clip (by @flexeykinDev). The first slice on the back of the video donut (in FLAC's place; FLAC stays in the preset list) opens your videos one after another in a clip window. Pick the start and end on an overview of the whole video, or press 15 s / 30 s / 60 s; Space plays the clip with its sound. C cuts at the playhead, Delete takes a piece out, and dragging a piece's edge trims it. Each piece can have its own volume, mute and speed (0.25× to 4×, the pitch kept), and the clip can get music from another file, Remove silence, fades in and out, and Ctrl+Z / Ctrl+Y. Fast, no re-encoding copies a plain clip in a moment but starts at the key frame before the start; cuts, speed, volume or fades are encoded with the preset's settings. Results are saved as {name}_clip. Needs FFmpeg.

  • Edit PDF pages (by @Perricheno). Edit, the first slice on the back of the PDF donut, opens into Crop, Rotate left, Rotate right, Pages, Split and Add. Crop and rotate change only the page boxes and the rotation, so text and drawings stay sharp and bookmarks and forms stay. Pages opens a page editor with thumbnails and a large preview: reorder, rotate and delete pages, add pages from another PDF, or extract the selected page as its own file.

  • Watermark, page numbers and a password (by @cre8ive-marketing). The PDF card of the preset editor has three new options for every PDF a preset writes, whatever it is made from: a Watermark text ("DRAFT"), large and light grey across each page; Page numbers ("3 / 10" at the bottom); and a Password to open (AES-256). With Merge into one PDF the pages are numbered through. The watermark and the numbers can't be selected or searched, and a PDF/A can't have a password. The password is saved with the preset in Filee's settings, but left out of the history and of Settings → General → Export.

  • PDF tables to Excel (issue #267, by @cre8ive-marketing). The XLSX preset now takes PDFs: every table drawn with lines becomes its own sheet, with merged cells, borders, column widths, and numbers, amounts, percentages and dates as real values (codes with a leading zero stay text). A table that goes on over the next page stays one sheet, without its repeated header. Text outside the tables is left out, tables without lines aren't found, and a PDF without ruled tables (or a scan) stops with a message. ODS and CSV work the same way. The XLSX preset isn't on the PDF donut; add it in Settings → Donut toolbar.

  • Spreadsheet Print Studio (by @Perricheno). PDF + Edit, the first slice on the back of the spreadsheets donut, opens an Excel workbook before it becomes a PDF: the sheets in output order on the left, the real PDF pages in the middle, and the page setup on the right (print area, paper, portrait or landscape, scale or fit to pages, margins, page order, hidden rows and columns, manual page breaks). A sheet can be split into regions with a page setup each. When a workbook asks for a tiny scale, or a very wide sheet has no print area, it offers a suggested layout. The preview is exactly what is exported, and your workbook isn't changed. Needs LibreOffice.

  • Replace the original (issue #332, by @cre8ive-marketing). A new option in the preset editor's output card, off unless you tick it. When a file's result has the same format as the file (Compress image, Rotate, Trim transparent borders …), the original goes to the Recycle Bin / Trash and the result takes its name and place. When the original can't go there (a network drive, a file open in another program), both are kept and the notice says why. It never applies to watch folders, files from a browser, ZIP results, files that become several, or the command line.

  • Trim transparent borders (issue #332, by @cre8ive-marketing). A new preset on the image donut's back face, after Remove background: a copy named name_trimmed, cropped to the pixels that aren't fully transparent. Pictures without transparency and animations stay as they are.

  • More formats, 263 in all.

    • FITS astrophotos (.fits, .fts; issue #460) from telescope cameras and capture or stacking programs such as N.I.N.A., on the image donut. To PNG, JPG and the other picture formats they're stretched automatically, like a capture program's preview, and a raw frame from a colour camera is debayered with the Bayer pattern in its header (Debayer FITS from a colour camera in the preset editor, on unless you turn it off). To TIFF they keep their data: FITS (astronomy) to TIFF is Linear: the data as it is (8 and 16 bits stay as they are, 32-bit and floating-point data become 32-bit floating point, never debayered) or Stretched, like a preview. PNG and JPG are 8-bit. Tile-compressed files (fpack, .fz) stop with a message asking to funpack them, and .fit is left to Garmin FIT files.
    • CRI USM game videos (.usm; issue #485), used for the cutscenes of many games, to MP4 and the other video and audio formats, with FFmpeg. Encrypted USM files can't be read.
    • iCalendar (.ics; issue #340, by @SeoJCalive): events and to-dos become CSV, one row each, and through it JSON and the other data formats; CSV goes back to .ics. The new "iCalendar" preset is on the back of the spreadsheets donut, after vCard. Recurring events keep their rule; they aren't expanded.
    • HAR network logs (issue #328): to JSON, YAML, XML, or a table with one request per row (CSV, spreadsheets, PDF).
    • Raw H.265 / H.264 streams (.h265, .265, .hevc, .h264, .264; issue #301) to MP4 and the other video formats, with FFmpeg.
    • Tajima DST embroidery (issue #397): the stitches at real size as PNG, JPG, PDF or SVG, a colour per thread (DST stores none). AutoCAD sheet sets, which also use .dst, are refused with the reason.
    • HP-GL plot files (.plt, .hpgl, .hpg, .hgl; issue #410), also AutoCAD's "plot to file", to PDF, PNG, JPG and SVG with their pen colours and widths. Text labels and fill patterns aren't drawn.
    • Lua, CSS and PowerShell (.lua, .css, .ps1; issues #388, #368, #442) become text like the other scripts: read, never run.
    • .png_large / .jpg_large downloads open as PNG and JPEG (issue #461, by @Nitjsefnie).

    Your donuts learn the new extensions, unless one of your own donuts already takes them.

  • CAD drawings.

    • One page per layout (issue #172, by @cre8ive-marketing). DWG / DXF → PDF makes a page for each paper-space layout, in tab order, with model space drawn through each viewport at its scale. Drawings without layouts come out as before, and SVG and pictures are still one picture of model space. Twisted views, layers frozen per viewport, clipped viewports and the layout's paper size and plot scale aren't followed yet.
    • AutoCAD version (issue #489, by @cre8ive-marketing). DWG and DXF presets have a "CAD drawing" card: 2018 (as before), 2013, 2010, 2007, 2004, 2000 or Same as the source, and DWG → DWG or DXF → DXF just changes the version. Objects the version doesn't have (multileaders, meshes …) are left out with a note. Before 2007, Korean, Chinese or Japanese text is saved in the code page that fits it. A 2007 DWG is saved as 2004, which AutoCAD 2007 opens.

  • Material You (by @gtxPrime). Settings → Theme → Theme style has Filee Soft (as before) and Material You, with Material 3 surfaces toned from your accent colour. The accent colours come as vibrant swatches and pastel presets.

  • Window size (by @flexeykinDev). Settings → Theme → Window size makes everything in Filee's windows larger or smaller (70 to 180 %), with Reset. In any window, Ctrl + mouse wheel and Ctrl + plus / minus do the same, and Ctrl + 0 goes back to 100 % (⌘ on a Mac). The donut and the toasts keep their size.

  • Preset tabs (issue #343, by @SeoJCalive). Available presets in Settings → Donut toolbar is split into tabs: All, Image, Document, Video & audio, Edit, 3D & CAD, Geospatial, Archive and Font; tabs with nothing for the selected donut are hidden. A search looks through every tab and also shows, dimmed and with the reason, presets the donut's files can't use.

  • Missing fonts (issue #413, by @Perricheno). When a DOCX, XLSX, PPTX or HWPX names fonts this computer doesn't have, the conversion still runs and its card lists them, with Get fonts opening each font's own page (Microsoft's, the project's, or Google Fonts). Nothing is downloaded or installed for you. Fonts embedded in the document, or with a look-alike installed (Calibri → Carlito), don't count. The command line reports them too.

  • Choose files on Home (by @gtxPrime). Double-click the drop zone to pick files; the donut opens at the pointer.

  • Updates on Linux (by @manish0467). A Filee installed with install.sh downloads and installs new versions itself, as on Windows: it checks the download against the release's checksums, closes, installs and starts again, and your settings, presets, history and engines stay. If the install fails, the previous version is put back and Filee says so. To get 2.1.0 over 2.0.0, unpack the package and run ./install.sh --upgrade, which keeps the engines you downloaded (without --upgrade, an existing install is still never overwritten).

  • Wayland (experimental).

    • GNOME (by @yanscholze). On GNOME Shell 45 to 50, install.sh adds the Shell extension "Filee donut at the cursor". Turn it on in Extensions (sign out and in again if it doesn't show), then hold Ctrl and drag a file in Files. No input group or root is needed. Selection shortcuts, Hold, and flipping the donut during a drag don't work there. install.sh and updates keep the extension current, and Settings → Shortcuts says when Filee is waiting for it or when the running extension belongs to another version (sign out and in again).
    • Hyprland (by @mahaveergurjar). The drag gesture 2.0.0 brought to KDE (FILEE_WAYLAND_GESTURES=1 and the input group) works on Hyprland too, with a few window rules. FILEE_USE_WAYLAND=1 runs Filee as a native Wayland app instead of through XWayland. installer/linux/INSTALL.txt has the steps.

  • macOS disk image (issue #379). Next to the tar.gz, each macOS package comes as a .dmg too: open it and drag Filee to Applications. The filee command still comes with the tar.gz's install.sh, and the first start still goes through Privacy & Security → Open Anyway.

  • Languages. Filee speaks French (by @devohmycode), Traditional Chinese, also for Hong Kong and Macau (by @LouisChen-TW), Nepali (by @smjrifle), Thai, with its own font (by @Sudo-Bannawat), Turkish, in Setup too (by @xmetropolicex), and European Portuguese, next to Brazilian Portuguese (by @Blackspirits). It picks them when Windows, macOS or Linux does: a PC set to Portugal gets European Portuguese, one set to Brazil Brazilian, and a language picked in Settings stays as it is.

Improved

  • Large spreadsheets to PDF. XLSX, XLS, ODS and CSV going to PDF or pictures through Filee's built-in route are drawn far faster: a 65-page workbook takes 25 seconds instead of 24 minutes, and the progress bar no longer stalls halfway.
  • Rows to repeat at top (issue #407, by @cre8ive-marketing). XLSX → PDF repeats the rows a sheet sets in Page Layout → Print Titles on every page, not only frozen rows.
  • Every audio track (issue #396, by @cre8ive-marketing). Video → video keeps all audio tracks (a film with several languages) with their language tags, not only the first. FLV and DV still hold one.
  • Cyrillic, Greek and Central European text to PDF (by @anatolykoptev). Russian, Greek, Polish, Czech, Turkish, Vietnamese and other text with letters beyond Western European ones came out of DOCX, Markdown, TXT, HTML, XLSX, PPTX and HWPX → PDF with letters on top of each other. Such documents now go through LibreOffice when it's installed; without it they convert as before.
  • Arabic in .xls (issue #345, by @cre8ive-marketing). Old Excel files with Arabic now take the route XLSX took in 2.0.0 (LibreOffice, or a message without it) instead of becoming PDFs with broken letters.
  • Word → Markdown (issue #391). Tables with merged cells become plain Markdown tables instead of HTML, pictures are linked relative to the result, and EMF / WMF pictures become PNG on Windows.
  • Crop (issue #369, by @cre8ive-marketing). The frame's centre snaps onto the picture's centre lines, with a dashed guide, while you drag it. The arrow keys still move it by a pixel.
  • The donut's flip (issue #371, by @SeoJCalive). Each slice now turns over on its own, in a short wave that starts where you point and spreads both ways, and the whole flip still takes 0.2 s. The face switches the moment the flip starts, so a file dropped during the flip goes to the new face's slice. With "Reduce animations" the faces still swap at once.
  • Recent conversions (by @gtxPrime) show thumbnails of videos too, with FFmpeg.
  • Installing an update (Windows, by @gtxPrime) from the sidebar, About or the tray shows a window with the download's progress.

Fixed

  • A TXT, Markdown or CSV file saved as "ANSI" was always read as Korean, so Chinese, Japanese or Western text turned into Hangul (issue #491, by @cre8ive-marketing). It's now read in the computer's own code page, and as Korean when it looks Korean or on a Korean PC. A Chinese file on an English PC still can't be told apart.
  • Check boxes, ticks, arrows and other symbols inserted from Wingdings, Webdings or Symbol came out of Word and PowerPoint → PDF or HWPX as black dots (issue #350). They're the right characters now.
  • On Linux without Korean fonts, DOCX, XLSX and other documents converted to PDF through rhwp came out without their text (by @Perricheno).
  • Spreadsheets converted to PDF through LibreOffice could get completely empty pages. They're removed, with a note; PDF/A results are left as LibreOffice wrote them (by @Perricheno).
  • A file with a file name token in its own name had it filled in: Minutes {date}.png became Minutes 20261022.jpg (by @Bortlesboat). Only the tokens in your file name pattern are filled in now.
  • One ZIP packed only the .shp of a Shapefile, and selecting a Shapefile with its .dbf, .shx, .prj … opened the donut for mixed files and failed once per companion. A Shapefile now goes into the ZIP with its companion files, and a selected set counts as one file (by @KAPPI1925).
  • Double-clicking the tray icon could open two main windows (Windows).
  • After quitting Filee from the tray, the mouse stuttered for about five seconds (issue #358).
  • Shortcuts (issue #450): the recorder couldn't take Space or Enter, so even Ctrl+Alt+Space couldn't be recorded again. Hold and the keyboard shortcut didn't work on files selected on the desktop. Hold never fired when it used the same keys and button as Drag. A keyboard shortcut is now judged by the window in front, not by where the pointer is. When Start at sign-in doesn't stick (security software, for example), the switch says so.
  • On macOS, the Accessibility alert showed at every start after an update or reinstall (issues #316, #426). It shows once, and the reminder says to remove Filee from the list with − and add it again with +. install.sh clears the download flag on Filee.app and replaces a filee link left behind by an app moved to the Trash.
  • On KDE Plasma with Wayland, the donut could open behind the file manager (by @Perricheno). After updating Filee, upgrade the KWin script: the kpackagetool6 line in installer/linux/INSTALL.txt with --upgrade instead of --install, then the reconfigure line (qdbus6, qdbus-qt6 or qdbus, depending on the distribution).
  • On macOS, one press of the flip key while dragging could flip the donut twice, back to the face it started on (issue #504, by @cre8ive-marketing). It flips once.
  • A glTF model whose buffer or texture names are percent-encoded (mesh%20data.bin) failed to find those files (by @Stamina9).
  • The sample switch in Settings → Theme's preview didn't react to clicks. It now flips on and off to show the theme's switch, with the mouse or Space, and still changes no setting (issue #363, by @Saad-elnagar).
  • The engine setup window ran off small or scaled screens with its buttons out of reach (issue #370). The list scrolls now, the buttons stay in the window, and Esc closes it.
  • A donut slice's small caption was cut off; it takes a second line where the slice has room (issue #361, by @devohmycode).
  • In Settings → Donut toolbar, a donut's count showed only its front face, and the preset search had no clear button and stayed when you chose another donut (issues #425, #427, by @cre8ive-marketing). The count shows both faces (10 · 9), every search box has an ×, and the preset search empties when you switch donuts.
  • Security (by @Bddgc): before the built-in updater runs a downloaded installer, it checks that Windows trusts its signature and that the publisher who signed the running Filee signed it too. From 2.1.0 on, an installer signed by anyone else, or not at all, is deleted and you're sent to the download page instead.

2.0.0

New

  • Filee's own installer (Windows). Filee-<version>-win-Setup.exe is now Filee's own installer instead of an Inno Setup one; the download names stay the same. It is one card in Filee's look, in every app language (Windows' display language first): Install, and Options for the language, folder, desktop icon, Explorer menu, starting at sign-in, filee on the PATH and the engines to download. While it installs, it shows this version's What's new slides. It installs over Filee 1.x, also from the built-in updater: same folder, your choices and one entry in Apps & Features, with settings, presets and engines kept. The uninstaller asks whether to delete your settings (kept unless you say so). Setup checks its files before changing anything and puts everything back if an install fails halfway. The usual switches still work (/SILENT, /VERYSILENT, /SUPPRESSMSGBOXES, /NORESTART, /DIR=, /LANG=, /TASKS=, /MERGETASKS=, /NOICONS, /CURRENTUSER, /LOG), and /NOLAUNCH doesn't start Filee at the end. Tools that unpacked the old Setup with innounp need the portable zip now.

  • What's new. The first time Filee starts after an update, a small window shows the new features as short animated slides (Previous / Next, ← / →, Esc). About → "What's new in Filee 2.0" opens them again. With "Reduce animations" each slide is a still picture.

  • Files from a web browser. Hold the shortcut key and drag a picture, a link to a file or a download out of Chrome, Edge, Firefox or Safari: the donut opens as it does for your own files, and dropping on a slice saves the file and converts it. The Home drop zone takes the same drags. Settings → General → "Files dragged from a browser" sets where they are saved (Downloads unless you choose another folder) and can keep only the converted file. A badge over the progress ring shows the download. Filee downloads a link itself, without your browser's sign-in, so a file behind a sign-in has to be saved from the browser first. Web pages, programs and scripts are refused, and nothing is run. Attachments dragged out of Outlook and files dragged out of a ZIP in Explorer open the donut too.

  • The donut's back face (issue #195). Every donut has a second set of up to 12 slices. While the donut is open, press Tab or turn the mouse wheel to flip it; the hub shows the hint when the back has something for your files. Built-in donuts come with a back face: Crop, Rotate, Flip, Remove background and Live Photo video on the image donut, Compress PDF on the PDF donut, frame extraction and Live / Motion Photos on the video donut, One ZIP on most. The Front / Back switch in Settings → Donut toolbar edits it, and Settings → Shortcuts → "Flip the donut" changes the key or turns the wheel off.

  • Crop (by @smjrifle). The Crop slice (on the back of the image donut) opens your pictures one after another in a crop window. Drag the frame or its corners, pick a ratio on the aspect dial (Free, Original, 1:1, 4:3, 3:2, 16:9, and their portrait forms; A over the picture opens it at the pointer), then Crop & Next (Enter) or Skip. The arrow keys move the frame by a pixel (Shift: 10), R resets and X swaps portrait and landscape. A strip shows the files, and a summary lists what was skipped or failed. The quality of the picture is kept; animated pictures aren't cropped.

  • Live Photos and Motion Photos (issue #174, by @SunGang-pine). "Extract Live Photo video" takes the video out of an Android Motion Photo, or out of the MOV next to an iPhone Live Photo (LIVP packages too), as MP4 or MOV. Experimental: "Live Photo (iPhone)" and "Motion Photo (Android)" turn a short clip of a video (0.5 to 5 s) into an iPhone Live Photo (a JPG or HEIC plus a MOV with the same name; import both into Photos together) or an Android Motion Photo (one NAME.MP.jpg). They aren't confirmed on every phone yet. Both need FFmpeg.

  • More formats, 255 in all.

    • OFD (by @MMNHHK): Chinese e-invoices and other OFD documents become DOCX, PDF, HWPX, TXT and the other document formats, with their seals. Built in.
    • MHTML / MHT web archives ("Webpage, Single File", issue #210) become HTML, PDF, DOCX, HWPX, TXT, Markdown or EPUB. Scripts and anything outside the archive are left out.
    • POTM (issue #213, by @ganeshmshetty): macro-enabled PowerPoint templates, to and from the other PowerPoint formats and to documents and PDF.
    • Geospatial data (by @KAPPI1925): Shapefile, GeoJSON, KML, KMZ, GPX and CSV with coordinates convert into each other on a donut of their own, built in. Results are in WGS 84 longitude / latitude; projected data is converted using its .prj. Save the result as a ZIP (a preset option, also for every geospatial result in Settings → General, and --zip on the command line) keeps a Shapefile's files together in one ZIP.
    • FBX 3D models (issue #148), read only: to GLB, glTF, STL, OBJ, 3MF, PLY and pictures.
    • JPEG XR (.jxr, .wdp, .hdp; issue #150), on Windows: HDR screenshots are tone-mapped instead of clipped.
    • Scripts and logs as text (issues #254, #273, #284, by @Mustafa1p): .log, .py, .pac, .bat and .command become UTF-8 TXT. They are read, never run.
    • Video CD .dat (issue #292) becomes MP4 or MKV with FFmpeg; other .dat files are refused.
    • .wbpz Workbench archives open as ZIP (issue #294).

    Your donuts learn the new extensions, unless one of your own donuts already takes them.

  • Playback speed (issue #158). GIF, WebP, APNG and MNG presets can make animations play from 0.25× to 4× as fast, also for video → GIF or APNG.

  • Theme (accent picker by @Mustafa1p, donut opacity by @gtxPrime, theme.json by @AkiVonAkira). Settings → Theme has a colour picker with a hex field next to the accent swatches, and Donut toolbar opacity (10 to 100 %, issue #276). Softness rounds the donut's slices too (issue #206). A theme.json next to settings.json can replace Filee's page, surface, text and status colours (docs/CUSTOM-THEMES.md).

  • Reset one donut (issue #205). Reset to default next to Delete profile in Settings → Donut toolbar puts a built-in donut back as it came, front and back. Your other donuts and your presets stay as they are.

  • Recent conversions (by @gtxPrime). Home has a search box over the list, thumbnails of pictures, and Open file and Open with next to the folder button. Settings → General → "Conversions to keep in the history" (50 to 2,000, 200 unless you change it).

  • Folders into one ZIP (issue #186, by @SonicaReddy and @gtxPrime). Dragged folders go into One ZIP with everything in them, and One ZIP is on the archives donut too. Other presets still don't take folders.

  • Watch folders that write into themselves (issue #234, by @Mustafa1p). A watch folder's output may be the folder it watches; its own results aren't converted again.

  • Merge order (issue #268, by @Mustafa1p). Merge PDF first shows the files in name order (2 before 10), with each file's folder. Move them up or down (Alt+↑ / Alt+↓) or cancel before anything starts.

  • AV1 on the graphics chip (issue #196). Use hardware acceleration (graphics chip) encodes AV1 too, on NVIDIA RTX 40, Intel Arc and Core Ultra, AMD RDNA 3 and newer, and through VA-API on Linux. Other chips leave AV1 to the usual encoder, as before.

  • A subfolder only when needed (issue #259, by @flexeykinDev). With "A subfolder", Only when a file becomes several saves a single result next to the original and keeps the subfolder for files that become several (a PDF split into pages).

  • Dock and menu bar (macOS, issue #132, by @SeoJCalive). Settings → General → Show Filee in the Dock and Show Filee in the menu bar. With both off, opening Filee again brings up its window.

  • macOS 13 (by @yoamzil). Filee runs on macOS 13 Ventura, not only 14 and newer.

  • Linux packages are no longer a preview.

1.10.0

New

  • PDF → one long image (issue #50). A multi-page PDF becomes a single tall image with the pages one under another, e.g. to post a whole document at once. Use Long image on the PDF donut (PNG), or tick "Stack the pages into one tall image" in any image preset. Animated GIF/WebP and PDF pages still become a moving video or a slideshow.
  • MOV ↔ MP4 without quality loss. When the new format can hold the video and sound as they are, like an iPhone video (HEVC or H.264 with AAC) going from MOV to MP4, Filee now only rewraps them instead of re-encoding: nothing is lost, HDR and 10-bit colour stay, and it takes seconds. The same goes for MKV, WebM and TS. Choosing a smaller size (e.g. 720p), another audio bitrate or quality Small still re-encodes.
  • Save images as HEIC (with FFmpeg). Any image Filee reads → HEIC, the format iPhones take photos in: about a quarter of a JPG's size at the same quality, stored in 512-pixel tiles like a phone photo, upright, with the colour profile and Exif kept. The HEIC preset is on the Presets page (quality 80); add it to a donut to use it. Transparent areas are filled with the preset's background colour.

  • In an installed copy, Update (bottom of the menu, tray menu, the update notice, Settings → General) now downloads the new installer inside Filee, checks it against the release's SHA-256 file and runs it without the setup wizard. Setup closes Filee, updates it, keeps your settings and engines and starts Filee again. Windows asks for administrator rights once.
  • The sidebar, tray menu, Settings → General and the notice show the download progress.
  • If the download or the installer fails (no connection, a file that doesn't match its checksum, an installer that won't start), Filee tells you, and after OK it opens filee.sh so you can download the new version there.
  • The portable copy still opens the release page: download the new ZIP and unpack it over the old folder.
  • Updating to 1.4.0 from an older version still goes the old way. From 1.4.0 on, it's one click.

Default save location

  • Settings → General → Default save location: next to the original (as before), in a subfolder such as converted, or in one fixed folder.
  • Every preset follows it unless you give the preset its own location (Presets → Output → Save to).
  • Built-in presets, and your presets that saved next to the original, follow the default from now on. Since the default starts as "next to the original", nothing changes until you pick another one.

Keep the original file dates for every conversion

  • New switch in Settings → General: converted files get the created and modified dates of the original, with every preset (photos, videos, PDFs, archive conversions).
  • Not when several files become one (merged PDF, several files packed into one ZIP): that file has no single original.
  • The per-preset option from 1.3.1 stays, for keeping dates with some presets only.
  • The filee command follows the default save location and this switch too.

Use the engines you already have

  • Settings → Engines → Use my copy… next to FFmpeg, calibre, Pandoc, Ghostscript and LibreOffice. Pick the program (ffmpeg.exe, ebook-convert.exe, pandoc.exe, gswin64c.exe or soffice.exe) and Filee uses it instead of downloading its own. Stop using it goes back.
  • FFmpeg needs ffprobe.exe in the same folder (most builds have both). Picking a build's main folder finds its bin folder too.
  • The filee command uses the same copies.

1.3.1

Keep the original file dates

  • Presets → Output → Keep the original file dates: converted files get the created and modified dates of the original, so converted photos still sort by when they were taken. On the command line: --keep-dates.

Conversions that were there but hard to find

  • New HWP preset (saved through HWPX). It is on the PDF, documents, HWP, spreadsheet, presentation, text and e-book donuts, so Word, PDF, Excel, PowerPoint, Markdown and EPUB files can be saved as .hwp directly.
  • On the donuts now: PDF → Markdown and EPUB, Word → PNG, HWP → JPG and EPUB. These worked before through another format, but weren't on any donut.
  • Existing donuts get the new entries once, unless a donut is full or already has them.

Texts

  • Plainer wording in English, Korean and Chinese.
  • Fixed: the Korean shortcut button said "recording", and removing a watch folder read like deleting it in Chinese.

1.3.0

The filee command line

  • Setup can add the filee command to PATH. filee convert converts files, wildcards (*.heic) and folders with --to <format> or one of your presets; filee watch converts files that land in a folder; filee formats and filee presets list what's available.
  • --json prints the result for scripts. Exit codes: 0 all converted, 1 some failed, 2 wrong arguments or a missing file, 3 nothing to convert. Guide: https://filee.sh/cli/

Watch folders

  • A new Watch folders page: files that land in a folder you choose are converted while Filee runs, once downloads and copies are complete. Keep the originals, or move them to an originals folder so the folder works like an inbox.

History

  • Settings → General: turn off the list of recent conversions, or clear it.

Fixes

  • Ctrl+drag stopped working after the Photos app had been opened, until Filee was restarted. The donut now stays on top of other windows.
