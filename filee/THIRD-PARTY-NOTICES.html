Windows 11 Explorer menu (FileeExplorerMenu.dll)

The DLL is Filee's own C code, compiled with the Zig toolchain (a build tool, not shipped) against the mingw-w64 Windows headers, without a C runtime. Pieces of these projects that can end up in the binary:

Installer

Filee-<version>-win-Setup.exe is Filee's own installer (src/Filee.Setup, MIT like the app). It contains the .NET runtime, Avalonia, SkiaSharp, HarfBuzzSharp, CommunityToolkit.Mvvm and SharpCompress (LZMA) listed in this file, the x86 branch filter of the LZMA SDK (public domain, Igor Pavlov, https://www.7-zip.org/sdk.html), and the published app as its payload. Filee 1.x's installer was built with Inno Setup, which is no longer used.

Documentation theme examples

The optional JSON recipes in docs/themes/ adapt palette data from Catppuccin, Nord, Dracula and VS Code's classic Monokai theme. Their source links, colour adjustments and copyright/license notices are in docs/themes/NOTICE.md. These are documentation examples, not runtime dependencies.
