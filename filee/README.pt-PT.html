Um conversor de ficheiros gratuito e de código aberto: basta arrastar e largar.
Mantém uma tecla premida (Ctrl, Option no macOS), arrasta ficheiros e larga-os num formato da barra circular que se abre junto ao cursor.

Instalação

Descarrega o Filee da página de versões.

  • Windows 10/11: executa Filee-<version>-win-Setup.exe ou extrai o win-Portable.zip e executa Filee.exe.
    • O Filee tem um instalador próprio, disponível nos idiomas da aplicação, que não precisa de mais nada no computador.
    • Permite adicionar o menu do Explorador, o arranque ao iniciar sessão, o comando filee e motores opcionais.
    • As instalações silenciosas aceitam as opções do Inno Setup (/VERYSILENT /SUPPRESSMSGBOXES).
  • macOS 13+ (versão de pré-visualização): extrai o pacote osx-arm64 ou osx-x64 e executa ./install.sh.
    • Também podes abrir o .dmg e arrastar o Filee para Aplicações (o comando filee é instalado pelo install.sh).
    • A aplicação ainda não foi notarizada pela Apple. Autoriza o primeiro arranque em Definições do Sistema → Privacidade e Segurança → Abrir mesmo assim.
  • Linux x64/ARM64 (Ubuntu 22.04+): extrai o pacote e executa ./install.sh (não precisa de acesso de administrador; requer Python 3).
    • Os gestos de arrastar são suportados em X11. Em Wayland, usa a zona de largada e o menu de contexto do gestor de ficheiros, ou consulta as integrações experimentais para GNOME, KDE Plasma e Hyprland no guia de instalação para Linux.

O Filee mostra as novas versões no menu e atualiza-se, mantendo as tuas definições e motores. Depois de uma atualização, algumas páginas apresentam as novidades.

Windows: o Filee não abre, sem janela nem mensagem de erro? Isto pode acontecer num Windows 10 que não é atualizado há muito tempo, num computador cujo processador suporta a proteção de pilha imposta por hardware (CET). O Windows ativa essa proteção, mas falta-lhe um componente de que o .NET precisa, pelo que o Filee e o instalador terminam de imediato.

  • Recomendado: instala as atualizações disponíveis do Windows (a atualização cumulativa mais recente).
  • Se não puderes atualizar: desativar a proteção apenas para o Filee costuma resolver o problema. Executa estes comandos no PowerShell como administrador:
Set-ProcessMitigation -Name Filee.exe -Disable UserShadowStack
Set-ProcessMitigation -Name filee-cli.exe -Disable UserShadowStack

Faz o mesmo para o nome do ficheiro do instalador (por exemplo, Filee-<version>-win-Setup.exe) ou usa o ZIP portátil, que precisa apenas destas duas linhas. Para reverter a alteração, remove as entradas em Segurança do Windows → Controlo de aplicações e browser → Definições de proteção contra exploits → Definições do programa.

Funcionalidades

  • Uma barra circular junto ao cursor: mantém uma tecla premida, arrasta ficheiros e larga-os num formato. Só aparecem formatos compatíveis com os ficheiros.
  • Diretamente do navegador: arrasta uma imagem, uma ligação para um ficheiro ou uma transferência do Chrome, Edge, Firefox ou Safari da mesma forma.
    • O Filee guarda o ficheiro na pasta Transferências (ou mantém apenas o ficheiro convertido) e converte-o.
    • Os ficheiros das ligações são descarregados sem usar a sessão iniciada no navegador.
  • Uma barra por tipo de ficheiro, organizada por arrastar e largar, com predefinições de:
    • qualidade, tamanho e DPI
    • páginas e compressão de PDF
    • vídeo e áudio
    • pasta de destino e nomes de ficheiro
  • Duas faces em cada barra circular: prime Tab ou roda a roda do rato enquanto está aberta para a virar e aceder a formatos e ferramentas menos comuns.
  • Recortar antes de converter: o segmento Recortar abre as imagens uma a uma. Arrasta a moldura, escolhe uma proporção e só essa parte é guardada.
  • Vários ficheiros ao mesmo tempo, em paralelo. Os percursos com várias etapas (HWP → HWPX → DOCX) são encontrados automaticamente.
  • Pastas monitorizadas convertem todos os ficheiros que nelas entram.
  • Conversões recentes na Página inicial, cada uma com uma miniatura: abre o resultado ou escolhe outra aplicação para o abrir.
  • Outras formas de converter: o menu de contexto, um atalho de teclado, a zona de largada e o comando filee.
  • Temas claro e escuro, com a tua cor de destaque e a opacidade da barra circular à tua escolha, em English, Español, 日本語, 한국어, 简体中文, 繁體中文, Polski, हिन्दी, Русский, العربية (da direita para a esquerda), Português (Brasil), Français, नेपाली, ไทย, Türkçe, Português (Portugal) e Deutsch.

Linha de comandos

O comando filee usa os mesmos motores e predefinições da aplicação (é adicionado pelo instalador ou pelo install.sh).

filee convert photo.heic --to jpg
filee convert *.png --to webp --quality 80 -o converted
filee watch D:\Inbox --to pdf --move-originals

Todos os comandos e opções: filee.sh/cli ou filee help.

Desenvolvimento

Compila com o SDK do .NET 10 em Windows, macOS ou Linux:

git clone https://github.com/KnifeLemon/Filee.git
cd Filee
pwsh build/fetch-engines.ps1 -Only rhwp,pandoc   # motores opcionais
dotnet run --project src/Filee.App
dotnet test

Política de assinatura de código

O Filee é desenvolvido e publicado por Myeonggu Kim (KnifeLemon).

  • As versões para Windows são assinadas com um certificado Certum de assinatura de código para projetos de código aberto, emitido a Myeonggu Kim ("Open Source Developer MYEONGGU KIM").
    • As versões anteriores, até à 2.0.0 inclusive, não estão assinadas.
    • O SmartScreen pode continuar a mostrar um aviso sobre uma versão nova até que esta tenha sido descarregada vezes suficientes ("Mais informações" → "Executar mesmo assim").
  • Os pacotes para macOS têm uma assinatura ad hoc e não foram notarizados pela Apple.
  • Só são assinados ficheiros compilados pelo fluxo de publicação do GitHub Actions deste repositório, e cada versão é assinada e aprovada manualmente.
    • As bibliotecas e os programas assinados pelos respetivos autores (.NET, SkiaSharp, ImageMagick, o runtime do Microsoft C++…) mantêm as suas assinaturas; os componentes incluídos sem assinatura (rhwp, 7-Zip e a maioria das bibliotecas) são assinados com o certificado do Filee, como parte do Filee.

Política de privacidade

O Filee converte os ficheiros no teu computador e nunca os envia para a Internet. Não recolhe dados de utilização nem envia telemetria. Só se liga à Internet:

  • para perguntar ao GitHub (api.github.com) se existe uma versão mais recente, pouco depois do arranque e, depois, a cada poucas horas. Podes desativar esta opção em Definições → Acerca de ("Procurar atualizações automaticamente").
  • para descarregar os motores de conversão que escolheres instalar, a partir dos endereços oficiais fixados em engines.json, e os idiomas de reconhecimento de texto (OCR) usados por uma predefinição, fixados em ocr-languages.json.
  • quando clicas numa ligação, que abre o navegador.
