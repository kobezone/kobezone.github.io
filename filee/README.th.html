ปรากฏตรงตำแหน่งเคอร์เซอร์
ไม่ต้องเปิดหน้าต่างแอป ฟอร์แมตที่เหมาะสมจะแสดงขึ้นตรงจุดที่คุณทำงานอยู่ โดยแสดงเฉพาะฟอร์แมตที่ใช้ได้กับไฟล์ที่คุณลากเท่านั้น 		267 ฟอร์แมต โดยไม่ต้องลงโปรแกรมอื่นเพิ่ม
รูปภาพ, PDF, Word, Excel, PowerPoint, HWP, อีบุ๊ก, ไฟล์บีบอัด, ฟอนต์, CAD, โมเดล 3D และข้อมูลเชิงพื้นที่ ทำงานได้โดยไม่ต้องมี Microsoft Office, Hancom Office หรือ LibreOffice 		ประมวลผลในเครื่องของคุณอย่างปลอดภัย
ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ Filee ทำงานแบบออฟไลน์ และบันทึกผลลัพธ์ไว้ข้างไฟล์ต้นฉบับในเครื่องของคุณ

ตัวอย่างการใช้งาน


รับชมวิดีโอสาธิตความยาว 27 วินาที และทดลองเดโมแบบอินเทอร์แอคทีฟได้ที่ filee.sh

การติดตั้ง

ดาวน์โหลดจากหน้า Releases

  • Windows 10/11: รัน Filee-<version>-win-Setup.exe หรือแตกไฟล์ win-Portable.zip แล้วเปิด Filee.exe
    • ตัวติดตั้ง Setup เป็นของ Filee เอง มีเมนูภาษาไทย และไม่ต้องติดตั้งโปรแกรมเสริมใดๆ
    • สามารถเพิ่มลงในเมนูคลิกขวาของ Explorer, ตั้งให้เปิดพร้อมระบบ, เพิ่มคำสั่ง filee และดาวน์โหลดเครื่องมือแปลงไฟล์เพิ่มเติมได้
    • รองรับการติดตั้งแบบเงียบด้วยพารามิเตอร์ของ Inno Setup (/VERYSILENT /SUPPRESSMSGBOXES)
  • macOS 13+ (รุ่นพรีวิว): แตกแพ็กเกจ osx-arm64 หรือ osx-x64 แล้วรัน ./install.sh
    • หรือเปิดไฟล์ .dmg แล้วลาก Filee ไปไว้ใน Applications (คำสั่ง filee มาพร้อมกับ install.sh)
    • เนื่องจากบิลด์ยังไม่ได้รับการรับรอง (notarized) ให้เปิดครั้งแรกผ่าน การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → Open Anyway
  • Linux x64/ARM64 (Ubuntu 22.04+): แตกแพ็กเกจแล้วรัน ./install.sh (ไม่ต้องใช้ root, ต้องการเพียง Python 3)
    • ท่าทางการลากต้องใช้ X11 ส่วนบน Wayland สามารถใช้งานผ่านพื้นที่วางไฟล์และเมนูคลิกขวาของโปรแกรมจัดการไฟล์

Filee จะแจ้งเตือนเมื่อมีเวอร์ชันใหม่และสามารถอัปเดตตัวเองได้ โดยยังคงการตั้งค่าและเครื่องมือแปลงไฟล์ทั้งหมดไว้ หลังการอัปเดตจะมีสไลด์สรุปฟีเจอร์ใหม่สั้นๆ ให้ดู

Windows: Filee ไม่เปิด (ไม่มีหน้าต่างหรือข้อผิดพลาด)? ปัญหานี้เกิดกับ Windows 10 ที่ไม่ได้อัปเดตมานาน บนพีซีที่โปรเซสเซอร์รองรับการป้องกันสแต็กที่บังคับใช้โดยฮาร์ดแวร์ (CET) Windows จะเปิดการป้องกันนี้ แต่ยังขาดส่วนที่ .NET ต้องใช้ Filee และตัวติดตั้งจึงปิดตัวทันที

  • แนะนำ: ติดตั้งอัปเดต Windows ที่มีอยู่ (อัปเดตสะสมล่าสุด)
  • หากอัปเดตไม่ได้: การปิดการป้องกันนี้เฉพาะ Filee มักจะได้ผล เปิด PowerShell ในฐานะผู้ดูแลระบบ แล้วเรียกใช้:
Set-ProcessMitigation -Name Filee.exe -Disable UserShadowStack
Set-ProcessMitigation -Name filee-cli.exe -Disable UserShadowStack

ทำแบบเดียวกันกับชื่อไฟล์ของตัวติดตั้ง (เช่น Filee-<version>-win-Setup.exe) หรือใช้ ZIP เวอร์ชันพกพา ซึ่งใช้แค่สองบรรทัดนี้ หากต้องการย้อนกลับ ให้ลบรายการเหล่านั้นใน ความปลอดภัยของ Windows → การควบคุมแอปและเบราว์เซอร์ → การตั้งค่าการป้องกันการโจมตีช่องโหว่ → การตั้งค่าโปรแกรม

ฟีเจอร์เด่น

  • แถบโดนัทตรงเคอร์เซอร์: กดปุ่มค้างไว้ ลากไฟล์ และปล่อยลงบนฟอร์แมตที่ต้องการ โดยจะแสดงเฉพาะฟอร์แมตที่เข้ากับไฟล์ของคุณ
  • ลากไฟล์จากเบราว์เซอร์ได้ทันที: ลากรูปภาพ ลิงก์ไฟล์ หรือรายการดาวน์โหลดออกจาก Chrome, Edge, Firefox หรือ Safari ในรูปแบบเดียวกัน
    • Filee จะบันทึกไฟล์ไว้ในโฟลเดอร์ดาวน์โหลด (หรือเก็บไว้เฉพาะไฟล์ที่แปลงแล้ว) และแปลงให้ทันที
    • ลิงก์จะถูกดาวน์โหลดโดยไม่ใช้การลงชื่อเข้าใช้ของเบราว์เซอร์
  • แยกแถบเครื่องมือตามประเภทไฟล์: จัดเรียงได้อิสระด้วยการลากวาง พร้อมพรีเซ็ตสำหรับ:
    • คุณภาพ, ขนาด, DPI
    • การแยกหน้าและบีบอัด PDF
    • วิดีโอและเสียง
    • โฟลเดอร์ปลายทาง และการตั้งชื่อไฟล์
  • โดนัทมีสองด้าน: กด Tab หรือหมุนล้อเมาส์ขณะโดนัทเปิดอยู่ เพื่อพลิกไปใช้ฟอร์แมตและเครื่องมืออื่นๆ ที่ด้านหลัง
  • ครอบตัดก่อนแปลง: ชิ้นส่วน 'ครอบตัด' จะเปิดรูปภาพขึ้นมาทีละรูป ให้คุณลากกรอบ ปรับสัดส่วน แล้วบันทึกเฉพาะส่วนที่ต้องการ
  • แปลงหลายไฟล์พร้อมกันแบบขนาน: เส้นทางการแปลงที่ต้องผ่านหลายขั้นตอน (เช่น HWP → HWPX → DOCX) จะทำงานโดยอัตโนมัติ
  • โฟลเดอร์เฝ้าติดตาม (Watch folders): แปลงไฟล์ทุกไฟล์ที่ถูกเพิ่มเข้ามาในโฟลเดอร์โดยอัตโนมัติ
  • ประวัติการแปลงล่าสุด: แสดงในหน้าแรกพร้อมรูปตัวอย่าง เปิดดูผลลัพธ์หรือเปิดด้วยแอปอื่นได้ทันที
  • ช่องทางอื่นในการแปลง: เมนูคลิกขวา, ปุ่มลัดแป้นพิมพ์, พื้นที่วางไฟล์ในหน้าแรก และคำสั่ง filee
  • รองรับธีมสว่างและมืด ปรับสีเน้น (accent colour) และความโปร่งใสของโดนัทได้ตามใจ รองรับภาษา English, Español, 日本語, 한국어, 简体中文, 繁體中文, Polski, हिन्दी, Русский, العربية (จากขวาไปซ้าย), Português (Brasil), Français, नेपाली, ไทย, Türkçe, Português (Portugal) และ Deutsch

การใช้งานผ่านบรรทัดคำสั่ง (Command line)

คำสั่ง filee ใช้เครื่องมือและพรีเซ็ตชุดเดียวกับตัวแอป (ติดตั้งผ่านตัวติดตั้งหรือ install.sh)

filee convert photo.heic --to jpg
filee convert *.png --to webp --quality 80 -o converted
filee watch D:\Inbox --to pdf --move-originals

ดูคำสั่งและตัวเลือกทั้งหมดได้ที่ filee.sh/cli หรือพิมพ์ filee help

การพัฒนา (Development)

บิลด์ด้วย .NET 10 SDK บน Windows, macOS หรือ Linux:

git clone https://github.com/KnifeLemon/Filee.git
cd Filee
pwsh build/fetch-engines.ps1 -Only rhwp,pandoc   # ดาวน์โหลดเครื่องมือแปลงไฟล์เสริม
dotnet run --project src/Filee.App
dotnet test

นโยบายการลงนามรหัส (Code signing)

Filee พัฒนาและเผยแพร่โดย Myeonggu Kim (KnifeLemon)

  • เวอร์ชัน Windows ได้รับการลงนามด้วยใบรับรอง Open Source Code Signing จาก Certum ที่ออกให้แก่ Myeonggu Kim ("Open Source Developer MYEONGGU KIM")
    • สำหรับเวอร์ชันก่อนหน้านั้น (จนถึง 2.0.0) จะไม่มีการลงนาม
    • SmartScreen อาจแจ้งเตือนในเวอร์ชันใหม่จนกว่าจะมียอดดาวน์โหลดเพียงพอ (เลือก "More info" → "Run anyway")
  • ส่วนแพ็กเกจบน macOS จะเป็นการลงนามแบบ ad-hoc และยังไม่ได้รับการรับรอง (notarized)
  • เฉพาะไฟล์ที่บิลด์ด้วยเวิร์กโฟลว์รีลีสของ GitHub Actions ในคลังนี้เท่านั้นที่ได้รับการลงนาม และทุกรีลีสจะถูกลงนามและอนุมัติด้วยตนเอง
    • ไลบรารีและโปรแกรมที่ผู้พัฒนาลงนามไว้แล้ว (.NET, SkiaSharp, ImageMagick, Microsoft C++ runtime …) จะคงลายเซ็นเดิมไว้ ส่วนองค์ประกอบที่รวมมาโดยไม่มีลายเซ็น (rhwp, 7-Zip และไลบรารีส่วนใหญ่) จะถูกลงนามด้วยใบรับรองของ Filee ในฐานะส่วนหนึ่งของ Filee

นโยบายความเป็นส่วนตัว

Filee ทำการแปลงไฟล์ภายในเครื่องของคุณเท่านั้น และไม่เคยอัปโหลดไฟล์ขึ้นอินเทอร์เน็ต ไม่มีการเก็บข้อมูลการใช้งานและไม่มี telemetry ใดๆ
การเชื่อมต่ออินเทอร์เน็ตจะเกิดขึ้นเฉพาะในกรณีต่อไปนี้:

  • ตรวจสอบเวอร์ชันใหม่กับ GitHub (api.github.com) หลังเปิดโปรแกรมและทุกๆ สองสามชั่วโมง (ปิดได้ที่ การตั้งค่า → เกี่ยวกับ "ตรวจสอบการอัปเดตอัตโนมัติ")
  • ดาวน์โหลดเครื่องมือแปลงไฟล์ที่คุณเลือกติดตั้ง จากแหล่งทางการที่ระบุไว้ใน engines.json และภาษาสำหรับการรู้จำข้อความ (OCR) ที่พรีเซ็ตใช้ ซึ่งระบุไว้ใน ocr-languages.json
  • เมื่อคุณคลิกลิงก์ ซึ่งจะเปิดหน้าเว็บในเบราว์เซอร์ของคุณ

ผู้สนับสนุน (Sponsor)

Filee ใช้งานได้ฟรีและจะฟรีตลอดไป หากคุณต้องการสนับสนุนการพัฒนา สามารถเลือกช่องทางที่สะดวกได้เลย (Fairy รองรับบัตรเกาหลีและระบบชำระเงินแบบง่ายของเกาหลี)

ชื่อหรือโลโก้ของคุณอยู่ตรงนี้ได้ ผู้สนับสนุนรายเดือนจะได้รับการแสดงชื่อไว้ที่นี่ และผู้สนับสนุนระดับโลโก้จะได้แสดงโลโก้ทั้งที่นี่และในหน้าเกี่ยวกับของ Filee ผู้ที่สนับสนุนครั้งเดียวก็ขอให้แสดงชื่อได้เช่นกัน
