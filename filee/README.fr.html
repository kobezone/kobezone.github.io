Un convertisseur de fichiers gratuit et open source qui s'utilise en glissant.
Maintenez une touche enfoncée (Ctrl, Option sur macOS), faites glisser des fichiers et déposez-les sur un format du menu circulaire qui s'ouvre sous votre curseur.

Installation

Téléchargez Filee depuis les Releases.

  • Windows 10/11 : exécutez Filee-<version>-win-Setup.exe, ou décompressez win-Portable.zip et lancez Filee.exe.
    • Le programme d'installation est celui de Filee, dans les langues de Filee, et ne demande rien d'autre sur le PC.
    • Il peut ajouter le menu de l'Explorateur, le démarrage à l'ouverture de session, la commande filee et des moteurs facultatifs.
    • Les installations silencieuses acceptent les options d'Inno Setup (/VERYSILENT /SUPPRESSMSGBOXES).
  • macOS 13+ (préversion) : décompressez le paquet osx-arm64 ou osx-x64 et lancez ./install.sh.
    • Ou ouvrez le .dmg et faites glisser Filee dans Applications (seul install.sh ajoute la commande filee).
    • L'application n'est pas encore notarisée : autorisez le premier lancement dans Réglages Système → Confidentialité et sécurité → Ouvrir quand même.
  • Linux x64/ARM64 (Ubuntu 22.04+) : décompressez le paquet et lancez ./install.sh (sans root, Python 3 requis).
    • Les gestes de glisser nécessitent X11. Sous Wayland, utilisez la zone de dépôt et le menu contextuel du gestionnaire de fichiers.

Filee signale les nouvelles versions dans son menu et se met à jour tout seul, en conservant vos paramètres et vos moteurs. Après une mise à jour, quelques diapositives présentent les nouveautés.

Windows : Filee ne démarre pas (ni fenêtre ni erreur) ? Cela arrive sur un Windows 10 qui n'a pas été mis à jour depuis longtemps, sur un PC dont le processeur prend en charge la protection de la pile appliquée par le matériel (CET). Windows active cette protection mais il lui manque un élément dont .NET a besoin, si bien que Filee et le programme d'installation s'arrêtent aussitôt.

  • Recommandé : installez les mises à jour Windows disponibles (la dernière mise à jour cumulative).
  • Si la mise à jour est impossible : désactiver la protection pour Filee seul fonctionne généralement. Exécutez ceci dans PowerShell en tant qu'administrateur :
Set-ProcessMitigation -Name Filee.exe -Disable UserShadowStack
Set-ProcessMitigation -Name filee-cli.exe -Disable UserShadowStack

Faites de même avec le nom de fichier du programme d'installation (par ex. Filee-<version>-win-Setup.exe), ou utilisez le ZIP portable, qui n'a besoin que de ces deux lignes. Pour annuler, supprimez ces entrées dans Sécurité Windows → Contrôle des applications et du navigateur → Paramètres de protection contre les exploits → Paramètres du programme.

Fonctionnalités

  • Un menu circulaire sous le curseur : maintenez une touche, faites glisser des fichiers et déposez-les sur un format. Seuls les formats adaptés aux fichiers apparaissent.
  • Directement depuis le navigateur : faites glisser de la même façon une image, un lien vers un fichier ou un téléchargement depuis Chrome, Edge, Firefox ou Safari.
    • Filee l'enregistre dans votre dossier Téléchargements (ou ne garde que le fichier converti) et le convertit.
    • Les liens sont téléchargés sans la session ouverte dans votre navigateur.
  • Un menu circulaire par type de fichier, organisé par glisser-déposer, avec des préréglages pour :
    • qualité, taille, DPI
    • pages et compression PDF
    • vidéo et audio
    • dossier de destination et noms de fichiers
  • Deux faces pour chaque menu circulaire : menu ouvert, appuyez sur Tab ou tournez la molette de la souris pour le retourner et accéder aux formats et outils moins courants.
  • Recadrer avant de convertir : la tranche Recadrer ouvre les images une par une. Faites glisser le cadre, choisissez des proportions, et seule cette partie est enregistrée.
  • Plusieurs fichiers à la fois, en parallèle. Les chaînes de conversion en plusieurs étapes (HWP → HWPX → DOCX) sont trouvées automatiquement.
  • Des dossiers surveillés convertissent chaque fichier qui y arrive.
  • Conversions récentes dans l'Accueil, chacune avec sa miniature : ouvrez le résultat, ou ouvrez-le avec une autre application.
  • D'autres points d'entrée : le menu contextuel, un raccourci clavier, la zone de dépôt et la commande filee.
  • Thèmes clair et sombre avec votre propre couleur d'accentuation et l'opacité du menu circulaire, en English, Español, 日本語, 한국어, 简体中文, 繁體中文, Polski, हिन्दी, Русский, العربية (de droite à gauche), Português (Brasil), Français, नेपाली, ไทย, Türkçe, Português (Portugal) et Deutsch.

Ligne de commande

La commande filee utilise les mêmes moteurs et préréglages que l'application (le programme d'installation ou install.sh l'ajoute).

filee convert photo.heic --to jpg
filee convert *.png --to webp --quality 80 -o converted
filee watch D:\Inbox --to pdf --move-originals

Toutes les commandes et options : filee.sh/cli ou filee help.

Développement

Compilez avec le SDK .NET 10 sous Windows, macOS ou Linux :

git clone https://github.com/KnifeLemon/Filee.git
cd Filee
pwsh build/fetch-engines.ps1 -Only rhwp,pandoc   # optional engines
dotnet run --project src/Filee.App
dotnet test

Politique de signature du code

Filee est développé et publié par Myeonggu Kim (KnifeLemon).

  • Les versions Windows sont signées avec un certificat de signature de code open source Certum délivré à Myeonggu Kim.
    • Les versions jusqu'à la 2.0.0 ne sont pas signées.
    • Windows SmartScreen peut encore afficher un avertissement pour une nouvelle version tant qu'elle n'a pas été assez téléchargée (« Informations complémentaires » → « Exécuter quand même »).
  • Les paquets macOS sont signés ad hoc et ne sont pas notarisés.
  • Seuls les fichiers produits par le workflow de publication GitHub Actions de ce dépôt sont signés, et chaque version est signée et approuvée manuellement.
    • Les bibliothèques et programmes déjà signés par leurs éditeurs gardent leur signature ; ceux qui arrivent sans signature (rhwp, 7-Zip et la plupart des bibliothèques) sont signés avec le certificat de Filee.

Politique de confidentialité

Filee convertit les fichiers sur votre propre ordinateur et ne les envoie jamais en ligne. Il ne collecte aucune donnée d'utilisation et n'envoie aucune télémétrie. Il ne se connecte à Internet que :

  • pour demander à GitHub (api.github.com) si une nouvelle version existe, peu après le démarrage puis toutes les quelques heures. Désactivez-le dans Paramètres → À propos (« Rechercher automatiquement les mises à jour »).
  • pour télécharger les moteurs de conversion que vous choisissez d'installer, depuis les emplacements officiels fixés dans engines.json, et les langues de reconnaissance de texte (OCR) qu'un préréglage utilise, fixées dans ocr-languages.json.
  • quand vous cliquez sur un lien, ce qui ouvre votre navigateur web.
