# 老头乐游戏厅更新记录

当前版本：1.7

旧版安卓包保留在对应的 GitHub Release（`apk-v1.6`、`apk-v1.7` 这样的标签）。`apk-v1` 和 Latest 下载地址始终指向最新安装包。

## v1.7

- 进游戏后默认收起顶部标题栏，右上角是圆形菜单：回到游戏列表、重新开始、设置、关闭。
- 从屏幕顶端下滑可以临时拉出标题栏。安卓返回键和浏览器后退回到游戏列表。
- 新增设置（首页和游戏菜单都能打开，存在 localStorage，所有游戏一起生效）：
  - 返回方式二选一：角落小按钮 / 顶部标题栏。默认小按钮。选标题栏时右上角按钮收起，标题栏上可以进设置；若关掉操作按钮或方向键，角落菜单会留下来。
  - 玩法说明、分数统计、操作按钮、屏幕方向键可以分别开关。默认说明收起，其余显示。
  - 关掉的操作按钮会进菜单。方向键关掉后不再占高度，贴在屏幕下边，菜单里也能点。
  - 可以一键恢复默认。
- 新增更新记录页 `changelog.html`。
- 安卓包按版本号发布（`apk-v1.7`），同时更新 `apk-v1` 作为最新版下载地址。
