# 老头乐游戏厅更新记录

当前版本：2.0

旧版安卓包保留在对应的 GitHub Release（`apk-v1.6`、`apk-v1.7` 这样的标签）。`apk-v1` 和 Latest 下载地址始终指向最新安装包。

## v2.0

- 斗地主（`games/doudizhu.html`）：三人经典规则。叫分 1–3，3 分立刻结束，无人叫分重发。地主拿底牌先出。牌型含单张、对子、三张、三带一、三带对、顺子（至少 5 张，不含 2 和王）、连对、飞机（不带、带单、带对）、四带二单、四带二对、炸弹、王炸。两个电脑会叫分、跟牌和出牌。春天、反春天和炸弹翻倍。竖屏点牌后出牌、不出、提示、重选。赢的盘数记在 `laotoule:ddz`。
- 纸牌接龙（`games/klondike.html`）：七列、四花色位，翻 1 张或翻 3 张。点选再点目标，双击或连点收到花色位。空列只收 K。提示、撤销、计时。最快秒数记在 `laotoule:klon`（越少越好）。
- 黄金矿工（`games/goldminer.html`）：摆钩，点画面或「放钩」。金子、石头、口袋、宝石用几何图形画出。重量影响收回速度，限时达到本关目标即过关，共 8 关。最高分记在 `laotoule:gold`。
- 华容道（`games/klotski.html`）：横刀立马，曹操走到出口获胜。另有近在咫尺。可点空格、滑动或方向键，直线无阻挡可一次滑多格，算一步。原创插画牌面（曹操、关羽、张飞、赵云、马超、黄忠、兵），曹操金边。最少步数记在 `laotoule:klot`。
- 数独：选中只高亮当前格。同数字浅色提示默认关闭，页内可开关。新增 4×4（2×2 宫）和 6×6（2×3 宫），各 10 道固定可重玩的题。9×9 仍按简单 / 中等 / 困难 / 专家生成唯一解。
- 24 点牌面改为固定 2×2 网格，居中、间距均匀。剩 3 张时下面一张居中，剩 2 张并排，剩 1 张居中，宽度与网格里的牌一致。
- 版本号 2.0。安卓包 versionName 2.0（versionCode 200），Release 标签 apk-v2.0。离线缓存名 `laotoule-v2.0`。

## v1.9

- 扫雷补上手机操作：底部大按钮在「挖开」和「插旗」之间切换；长按约 400 毫秒插旗并震动，松手不会再挖开；点已打开的数字可以和弦翻开周围；屏蔽系统长按菜单、选字和双击放大。简单 9×9 在 360×640 竖屏整盘可见。电脑右键插旗保留。
- 贪吃蛇慢速间隔由 200 毫秒改为 300 毫秒（大约慢 50%）。中速 140、快速 90 不变。已保存的慢速 200 会迁到 300。
- 蜘蛛纸牌难度按钮改为「初级」「中级」「高级」，360 宽竖屏一行排开。单色 / 双色 / 四色规则不变。
- 新工具「大字报」（`games/bigtext.html`）：最多 12 个字，超出截断并提示。背景有红、黑、蓝、黄、绿、白和自定义色，文字颜色可自动对比或自选。初始字号约为屏宽 / 3.5，横竖屏都会重算，可调小，自动换行居中。文字效果：普通、流光溢彩（渐变裁字并流动）、霓虹灯牌（发光并轻微呼吸闪烁）、立体字、彩色跳动、跑马灯。动画用 transform 或 background-position，并尊重 prefers-reduced-motion。全屏只留文字和背景，点屏幕退出，并尝试阻止息屏。文字、颜色、大小和效果记在 localStorage。
- 版本号 1.9。安卓包 versionName 1.9，Release 标签 apk-v1.9。离线缓存名 `laotoule-v1.9`。

## v1.8

- 中国象棋：完整规则（照面、蹩马腿、塞象眼、过河兵、将军 / 将死 / 困毙）。人机三档用 alpha-beta，困难档限时出招。可悔棋、提示、重开、执红或执黑，上一步高亮，自动存档。
- 数独：生成唯一解。简单 / 中等 / 困难 / 专家。铅笔标记、擦除、撤销、提示、错误高亮、计时、同数字高亮、大号数字键。
- 24点：1 到 13，只出有解的题。点牌和运算符，可撤销、跳过、看答案，计分和连胜。简单模式只用 1 到 10，牌面可显示成 A/J/Q/K 或数字。
- 版本号 1.8。安卓包 versionName 1.8，Release 标签 apk-v1.8。

## v1.7

- 进游戏后默认收起顶部标题栏，右上角是圆形菜单：回到游戏列表、重新开始、设置、关闭。
- 从屏幕顶端下滑可以临时拉出标题栏。安卓返回键和浏览器后退回到游戏列表。
- 新增设置（首页和游戏菜单都能打开，存在 localStorage，所有游戏一起生效）：
  - 返回方式二选一：角落小按钮 / 顶部标题栏。默认小按钮。选标题栏时右上角按钮收起，标题栏上可以进设置；若关掉操作按钮或方向键，角落菜单会留下来。
  - 玩法说明、分数统计、操作按钮、屏幕方向键可以分别开关。默认说明收起，其余显示。
  - 关掉的操作按钮会进菜单。方向键关掉后不再占高度，贴在屏幕下边，菜单里也能点。
  - 可以一键恢复默认。
- 新增更新记录页 `changelog.html`。
- 安卓包按版本号发布（`apk-v1.7`），同时更新 `apk-v1` 作为最新版下载地址。
